# Hashtag Filter

Plugin for sGram / exteraGram: shows only channel posts that contain the chosen hashtags. Posts without them are hidden.

Плагин для sGram / exteraGram: в канале остаются только посты с выбранными хештегами, остальные скрываются.

## Возможности

- Несколько тегов сразу: режим «любой из» (по умолчанию) или «все сразу».
- Фильтр запоминается для каждого канала отдельно.
- Альбомы с тегом в подписи показываются целиком.
- Служебные сообщения не скрываются.
- Подсказка с тегами, которые встречаются в канале.
- Плагин работает только в канале с включённым фильтром, остальные чаты не замедляет.

## Использование

1. Установите `hashtag_filter.plugin`.
2. Откройте канал → «⋮» → **«Фильтр по хештегам»**.
3. Впишите теги через пробел или запятую (`#music #rock`, «#» можно не писать), при необходимости отметьте «все теги», нажмите «Применить».
4. Чтобы вернуть все посты — «Выключить» в том же окне.

## Usage

Channel «⋮» → **«Фильтр по хештегам»** → enter tags (`#music #rock`), optionally require all of them → «Применить». «Выключить» shows all posts again.
